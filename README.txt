PIKA CAKE — VS CODE PROJECT

Cara menjalankan:
1. Extract folder pika-cake-website.
2. Buka folder tersebut di Visual Studio Code.
3. (Disarankan) Install extension "Live Server".
4. Klik kanan index.html > Open with Live Server.

File:
- index.html       Struktur website
- style.css        Warna, layout, animasi, dan responsive design
- script.js        Navbar mobile, efek tilt, dan pemutar musik
- assets/          Foto yang kamu upload dan lagu Glue Song

Yang perlu kamu ubah:
- Link WhatsApp: cari https://wa.me/ di index.html lalu ganti dengan https://wa.me/62XXXXXXXXXX
- Menu dan deskripsi cake: edit bagian #menu di index.html.
- Nama/judul foto: edit caption pada bagian #gallery.

Catatan musik:
Website mencoba autoplay saat halaman dibuka. Browser modern sering memblokir autoplay dengan suara sampai pengunjung berinteraksi.
Kalau autoplay diblokir, tekan tombol play di kiri bawah. File musik lokal ada di assets/glue-song.mp3.

Catatan foto:
Foto anime dan foto Pika dipisahkan menjadi bagian masing-masing. Gunakan foto pribadi hanya dengan izin pemiliknya.
